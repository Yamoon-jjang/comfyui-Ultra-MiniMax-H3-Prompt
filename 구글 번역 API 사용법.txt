Ultra MiniMax H3 Prompt V3.50
Google 번역 API 사용법

※ 이 문서는 Ultra MiniMax H3 Prompt의 한국어→영어 자동 번역 기능과 Google Cloud Translation API Key 사용법을 설명합니다.
※ Google Cloud의 화면, 가격, 무료 제공량은 Google 정책에 따라 바뀔 수 있습니다. 아래 비용 정보는 2026-08-25 확인 기준입니다.

============================================================
1. 왜 Google 번역 API Key 기능이 추가되었나요?
============================================================

Ultra MiniMax H3 Prompt는 장면 설명만이 아니라 다음과 같은 비대사 설명문에 한국어→영어 자동 번역을 사용할 수 있습니다.

- 장면 설명
- 시간순 진행의 행동 지시
- 인물 외형·의상·음성 특징 설명
- 환경음·동작음 설명
- 배경 음악 설명
- 내레이터 등 비대사 설명
- R2V의 일반 Reference 원본 설명과 결과 반영 지시

실제 대사, R2V의 정확한 원본 대사·가사, 화면에 보이는 글자·UI처럼 원문 보존이 필요한 내용은 번역하지 않습니다.

API Key를 설정하지 않아도 기존 무료 번역 경로를 사용할 수 있습니다. 그러나 무료·익명 번역 경로는 공식적으로 개인별 사용량이 보장되는 Cloud Translation API가 아니므로 정상적인 ComfyUI 사용 중에도 서버의 자동화 감지, 공인 IP 공유, 일시적인 요청 집중, 무료 서비스의 자체 제한 등에 의해 HTTP 429(Too Many Requests)가 발생할 수 있습니다.

429가 발생했다고 해서 사용자가 스팸 번역을 했다는 뜻은 아닙니다. 서비스가 현재 요청을 제한하고 있다는 뜻입니다. 무료 경로의 제한 해제 시간은 일정하게 보장되지 않습니다.

공식 Google Cloud Translation API Key를 설정하면 노드는 Google Cloud Translation Basic v2의 공식 번역 경로를 우선 사용할 수 있습니다.
이 노드는 API Key 인증을 공식 지원하는 Cloud Translation Basic(v2)의 일반 NMT 번역을 사용합니다. Advanced(v3)용 서비스 계정/OAuth 설정은 필요하지 않습니다.

============================================================
2. 번역 방식과 우선순위
============================================================

[설명문 자동 번역 = 사용 안 함 · 입력 그대로]
- 온라인 번역 요청을 하지 않습니다.
- 한국어를 포함한 비대사 설명문을 입력 그대로 사용합니다.
- 저장된 Google API Key가 있어도 번역 요청을 하지 않습니다.
- 번역을 꺼도 저장된 Key 자체는 삭제되지 않습니다.

[설명문 자동 번역 = 자동 · 한국어→영어 / 영어는 그대로]
- 이미 영어인 설명은 그대로 사용합니다.
- 한국어가 필요한 경우 자동 번역을 시도합니다.
- 기존 성공 번역 캐시가 있으면 캐시를 가장 먼저 사용합니다.
- 캐시에 없고 Google Cloud API Key가 저장되어 있으면 공식 Google Cloud Translation Basic v2를 우선 사용합니다.
- 공식 API가 실패하면 기존 무료 Google/MyMemory 등의 fallback 경로를 계속 시도합니다.

============================================================
3. 번역 캐시는 어떻게 동작하나요?
============================================================

노드는 불필요한 재번역과 API 호출을 줄이기 위해 성공한 Google 번역 결과를 ComfyUI 사용자 폴더에 캐시합니다.

- 최대 약 2,048개 번역 결과
- 약 30일 보존
- ComfyUI를 재시작해도 재사용
- 같은 문장의 끝 공백, Unicode NFC, 개행 형식 정도만 안전하게 정규화
- 단어, 문장부호, 내부 공백 등이 달라지면 별도 문장으로 취급될 수 있음
- MyMemory 결과는 재시작 후 유지되는 persistent cache에는 저장하지 않음

따라서 공식 Google API를 사용하더라도 이미 캐시에 있는 같은 문장은 Google에 다시 보내지 않으므로 사용량과 비용을 줄이는 데 도움이 됩니다.

============================================================
4. Google Cloud Translation API는 무료인가요?
============================================================

API Key 자체를 만드는 데 별도 비용이 부과되는 것은 아닙니다. 비용은 Cloud Translation API에 실제로 보낸 번역 사용량을 기준으로 계산됩니다.

2026-08-25 Google 공식 가격 정책 확인 기준, 일반 NMT 텍스트 번역은:

- 매월 첫 500,000자: 무료
  (매월 최대 US$10 크레딧으로 적용)
- 월 500,000자를 초과한 부분: US$20 / 1,000,000자
- 비용은 API로 전송된 원문 문자 수를 기준으로 하며 공백도 문자 수에 포함됩니다.
- Basic(v2)와 Advanced(v3)의 일반 NMT 무료 크레딧은 합산 적용됩니다.
- 무료 크레딧은 다음 달로 이월되지 않습니다.

즉 현재 정책이 계속 유지되고 일반 NMT 사용량이 매월 500,000자 이내라면 매월 반복해서 무료 범위로 사용할 수 있습니다. 이것은 1회성 체험판 무료가 아닙니다.

다만 “영구적으로 50만 자 무료가 보장된다”는 의미는 아닙니다. Google은 향후 가격이나 무료 제공량을 변경할 수 있으므로 장기간 사용 시 공식 가격 페이지를 확인하세요.

공식 가격:
https://cloud.google.com/products/translate/pricing

중요:
- Google Cloud Translation을 실제로 사용하려면 Billing(결제 계정) 연결이 필요합니다.
- 무료 범위 안에서 사용하더라도 Billing 활성화는 필요합니다.
- 이 노드는 현재 Google Cloud의 월간 500,000자 사용량을 직접 집계하거나 과금 직전에 자동 차단하는 기능은 제공하지 않습니다. 사용량과 비용은 Google Cloud Console에서 확인하세요.

5. Google Cloud Translation API Key 만드는 방법
============================================================

Google Cloud Console:
https://console.cloud.google.com/

1) Google Cloud 프로젝트 만들기 또는 기존 프로젝트 선택
------------------------------------------------------------
- Google Cloud Console에 로그인합니다.
- 새 프로젝트를 만들거나 번역용으로 사용할 기존 프로젝트를 선택합니다.

2) Billing 연결 확인
------------------------------------------------------------
- 프로젝트에 결제 계정이 연결되어 있는지 확인합니다.
- Cloud Translation을 사용하려면 Billing(결제)을 반드시 활성화해야 합니다.

Billing:
https://console.cloud.google.com/billing

3) Cloud Translation API 활성화
------------------------------------------------------------
- API 및 서비스 → 라이브러리로 이동합니다.
- `Cloud Translation API`를 검색합니다.
- Cloud Translation API를 선택하고 `사용` 또는 `ENABLE`을 누릅니다.

직접 페이지:
https://console.cloud.google.com/apis/library/translate.googleapis.com

활성화가 완료되면 관리 화면에 `사용 설정됨`과 같은 상태가 표시됩니다.

4) API Key 만들기
------------------------------------------------------------
- API 및 서비스 → 사용자 인증 정보로 이동합니다.
- `사용자 인증 정보 만들기` → `API 키`를 선택합니다.
- 기존 API Key가 있다면 새 키를 만들지 않고 기존 키를 사용할 수도 있습니다.

Credentials:
https://console.cloud.google.com/apis/credentials

5) 반드시 API 제한을 설정하는 것을 권장합니다
------------------------------------------------------------
- 생성한 API Key의 상세 설정을 엽니다.
- `API 제한사항`에서 Key 사용 API를 제한합니다.
- `Cloud Translation API`만 선택하고 저장하는 것을 권장합니다.

이렇게 하면 Key가 실수로 노출되더라도 다른 Google API에 사용될 위험을 줄일 수 있습니다.

ComfyUI는 사용자의 로컬 Python 백엔드에서 Google API를 호출하므로 웹사이트 HTTP referrer 제한은 일반적인 로컬 ComfyUI 사용과 맞지 않을 수 있습니다. 고정된 외부 공인 IP 환경을 정확히 이해하고 있지 않다면 애플리케이션 제한은 잘못 설정해 정상 호출을 막지 않도록 주의하세요. API 제한은 Cloud Translation API로 설정하는 것을 강하게 권장합니다.

Google 공식 API Key 보안/제한 안내:
https://cloud.google.com/docs/authentication/api-keys

6. Ultra MiniMax H3 Prompt에 API Key 설정하기
============================================================

Main 노드와 R2V 노드 모두 같은 Google Translation API 설정을 공유합니다.

1) 노드의 `설명문 자동 번역`을
   `자동 · 한국어→영어 / 영어는 그대로`로 설정합니다.

2) 바로 아래에 나타나는
   `Google 번역 API 설정` 버튼을 누릅니다.

3) `Google Cloud Translation API Key` 입력란에 Google에서 발급한 Key를 붙여 넣습니다.

4) 저장하기 전에 확인하려면 `연결 테스트`를 누릅니다.
   - 입력란에 새 Key가 있으면 그 Key를 시험합니다.
   - 입력란이 비어 있으면 현재 저장되어 있는 Key를 시험합니다.

5) 테스트가 성공하면 `키 저장`을 누릅니다.

6) 버튼에 `Google 번역 API · 키 저장됨`이 표시되면 로컬 저장 상태입니다.

7) Key를 제거하려면 설정창에서 `저장된 키 삭제`를 누릅니다.
   삭제 후 자동 번역은 기존 무료 번역 경로를 사용합니다.

`설명문 자동 번역`을 `사용 안 함 · 입력 그대로`로 바꾸면 Google 번역 API 설정 버튼은 화면에서 숨겨집니다. 저장된 Key는 지우지 않으므로 다시 자동 번역으로 바꾸면 그대로 사용할 수 있습니다.

============================================================
7. API Key는 어디에 저장되나요? 안전한가요?
============================================================

API Key는 노드의 INPUT_TYPES 일반 위젯 값으로 저장하지 않습니다.

따라서 다음 위치에는 Key가 포함되지 않도록 설계되어 있습니다.

- ComfyUI workflow JSON
- 노드 properties
- prompt payload
- 공유하는 워크플로우 파일

Key는 ComfyUI 사용자 디렉터리 아래의 Ultra MiniMax H3 Prompt 전용 로컬 설정에 저장됩니다. 현재 파일명은:

user/ultra_minimax_h3_prompt/translation_api_config_v1.json

입니다. 실제 `user` 폴더의 위치는 ComfyUI 설치/실행 방식에 따라 달라질 수 있습니다.

설정창은 저장되어 있는 Key 문자열을 브라우저에 다시 전송해서 보여주지 않습니다. `입력 중인 키 표시`는 사용자가 현재 입력란에 새로 입력한 문자열만 표시합니다.

주의:
- API Key 전체를 인터넷 게시판, Discord, GitHub, 워크플로우 설명 등에 올리지 마세요.
- 다른 사람에게 자신의 Key를 배포하지 마세요.
- Key가 노출됐다고 생각되면 Google Cloud Console에서 즉시 해당 Key를 교체하거나 삭제하세요.
- 가능하면 API 제한을 Cloud Translation API로 지정하세요.

8. 무료 번역과 공식 API 중 무엇을 사용해야 하나요?
============================================================

[API Key 없이 무료 번역]
장점:
- 별도 Google Cloud 설정 없이 바로 사용 가능
- 비용 없음

주의:
- 무료/익명 번역 서비스의 429 제한이 발생할 수 있음
- 제한 해제 시간을 정확히 보장할 수 없음
- 공인 IP를 여러 사람이 공유하는 환경에서는 본인의 사용량이 적어도 제한될 수 있음

[Google Cloud Translation API Key 사용]
장점:
- 공식 Google Cloud Translation Basic v2 사용
- 프로젝트별 사용량/할당량 관리 가능
- 무료 익명 endpoint의 자동화/IP 제한과 분리됨
- 현재 일반 NMT 기준 월 첫 500,000자 무료 정책 이용 가능

주의:
- Google Cloud 프로젝트와 Billing 활성화가 필요
- 월 무료 제공량을 넘으면 요금이 발생할 수 있음
- 공식 API도 프로젝트 quota/rate limit을 초과하면 제한될 수 있음

안정적인 자동 번역이 중요한 사용자는 공식 API Key 사용을 권장합니다.

9. 오류별 간단한 확인 방법
============================================================

[HTTP 429 / rate limit / quota]
- 무료 번역 경로라면 잠시 번역 요청을 중단하고 기다려 보세요.
- 공식 API라면 Google Cloud Console의 Cloud Translation 할당량/사용량을 확인하세요.
- 같은 문장을 반복해서 실행하는 경우 캐시가 적용되는지도 확인하세요.

[API Key 또는 프로젝트 설정 오류 / 400, 401, 403]
다음을 확인하세요.
- API Key를 정확히 입력했는지
- 현재 프로젝트에서 Cloud Translation API가 `사용 설정됨`인지
- Billing이 연결되어 있는지
- API Key의 API 제한에 Cloud Translation API가 허용되어 있는지
- 애플리케이션 제한을 잘못 걸어 로컬 ComfyUI 요청을 차단하지 않았는지

[연결 테스트 실패]
- 인터넷 연결 확인
- Google Cloud 서비스 상태 확인
- 새 Key를 입력했다면 저장 전에 `연결 테스트`로 먼저 확인
- 이미 저장한 Key를 검사하려면 입력란을 비운 상태로 `연결 테스트` 실행

[API Key 삭제 후에도 번역됨]
정상입니다. 공식 Key를 삭제하면 자동 번역은 기존 무료 번역 경로를 사용할 수 있습니다.
온라인 번역을 완전히 끄려면 `설명문 자동 번역`을 `사용 안 함 · 입력 그대로`로 선택하세요.

요약
============================================================

- 번역 OFF: 온라인 번역 요청 0회, 입력 그대로 사용
- 자동 번역 + Key 없음: 캐시 → 기존 무료 번역 경로
- 자동 번역 + Key 있음: 캐시 → Google Cloud Translation Basic v2 → 기존 무료 fallback
- API Key는 workflow에 저장되지 않음
- 현재 일반 NMT 가격 정책: 매월 첫 500,000자 무료, 초과분은 US$20/100만 자
- 현재 정책이 유지되는 동안 월 500,000자 이하라면 매월 반복 무료 범위
- Google의 가격/무료 정책은 향후 변경될 수 있으므로 공식 가격 페이지를 확인할 것
